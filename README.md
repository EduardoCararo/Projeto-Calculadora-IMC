# 📏 Calculadora de IMC

Uma calculadora simples e intuitiva desenvolvida com **HTML**, **CSS** e **JavaScript**.  
Este aplicativo web permite ao usuário inserir seu **peso (kg)** e **altura (m)** para calcular automaticamente o **Índice de Massa Corporal (IMC)**, exibindo também a **classificação** de acordo com o resultado.

---

## 🔗 Live Preview

Insira seu peso e altura, clique em **"Calcular"**, e veja o resultado do IMC com a respectiva classificação.

## 🧠 Lógica do Cálculo do IMC

**Fórmula:**  
`IMC = peso / (altura * altura)`

| Faixa de IMC       | Classificação    |
|--------------------|------------------|
| Menor que 18.5     | Abaixo do peso   |
| Entre 18.5 e 24.9  | Peso normal      |
| Entre 25 e 29.9    | Sobrepeso        |
| 30 ou mais         | Obesidade        |
